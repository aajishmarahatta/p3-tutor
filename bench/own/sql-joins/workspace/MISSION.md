# Mission

I want to learn SQL joins because I'm interested in Computer Science and Data Science, and I want to get better at working with data stored across multiple tables. I already understand basic SQL commands like SELECT, WHERE, and ORDER BY, but I sometimes get confused when I need to combine information from different tables.

My goal is to understand the differences between INNER JOIN and LEFT JOIN, predict what rows a query will return, and recognize why joins sometimes create duplicate rows. I also want to learn how to count records correctly after joining tables.

By the end, I want to confidently write and explain SQL queries that combine related tables, choose the appropriate join type for a problem, and avoid common mistakes when analyzing data.
