# 0001 - First session

## Topic
Introduction to SQL and relational databases

## What I worked on
I practiced using SELECT, WHERE, and ORDER BY to retrieve, filter, and sort data from a single table. I also reviewed how tables can be connected using primary keys and foreign keys.

I looked at simple examples using students and enrollments tables to understand how records from two tables relate to each other.

## What I learned
- I can write basic SELECT queries and use WHERE to filter results.
- I understand that a primary key identifies a record and a foreign key can reference a record in another table.
- I know that an INNER JOIN combines matching rows from two tables.
- I have been introduced to LEFT JOIN, but I still need practice understanding unmatched rows.

## Where I struggled
I sometimes assumed that each student would appear only once after joining tables. I also had trouble predicting how many rows a query would return when one student had multiple enrollment records.

I was unsure when COUNT(*) would give the number of students versus the number of enrollment records.

## Next steps
Practice predicting the results of INNER JOIN and LEFT JOIN using small tables. Then learn how one-to-many relationships affect result counts and when COUNT(DISTINCT ...) is needed.

## Learner preferences
I learn best with short explanations, worked examples, small tables, and practice questions where I predict an answer before seeing the explanation.
