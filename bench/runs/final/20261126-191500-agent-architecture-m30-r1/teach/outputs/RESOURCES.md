# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering, Sep 2025)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Opened and read. Defines context, context rot and attention budget; covers compaction, structured note-taking, just-in-time retrieval and sub-agents. Use for: anything about what an agent keeps in context and how it remembers.
- [Docs: "Understanding the context window" (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Opened and read. Explains how tokens count toward the window, what happens on overflow, and server-side compaction. Use for: the mechanics of the context window and token counting.
- [Article: "LLM Powered Autonomous Agents" by Lilian Weng (2023)](https://lilianweng.github.io/posts/2023-06-23-agent)
  Seen in search results, not opened. Treats memory (short-term = context, long-term = external store with retrieval) as a core agent component. Use for: the short-term/long-term memory framing.
