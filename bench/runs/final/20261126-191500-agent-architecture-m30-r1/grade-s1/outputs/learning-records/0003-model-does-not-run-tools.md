# Misconception to work on: the model runs the tools itself (M4)

On quiz 0001 the learner chose that the model reads the calendar on its own and answered that one model call covers three tool calls.
They hold that the model runs tools inside a single call; in fact the program runs each tool and calls the model again with the result. They also added that the model remembers earlier tool choices across sessions (M3).

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6.

**Implications:** Revisit who runs the tool and why every step is a separate model call before moving to context and memory; M3 fits naturally into the memory lesson.
