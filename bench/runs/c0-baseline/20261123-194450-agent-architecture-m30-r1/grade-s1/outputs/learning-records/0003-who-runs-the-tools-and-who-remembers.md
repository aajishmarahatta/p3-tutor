# Open misconceptions: the model runs tools itself (M4) and remembers on its own (M3)

On quiz 0001 (first attempt) Riley got the loop (q1) and the stopping condition (q3) right, and knew tools are chosen from their descriptions. Riley also believed that the model opens systems and runs the tools itself (M4, q2 and q4), and that it remembers earlier sessions on its own (M3, q6).
Both matter for the makerspace assistant: M4 hides that every step is a separate, paid model call, and M3 hides that between-session memory has to be built by the program.

**Evidence:** quiz 0001, submission s1, items q2, q4, q6. Submission s2 (from memory, four days later) is not yet graded and will show whether this has been corrected.

**Implications:** Before teaching memory, have Riley mark each step of a request as model output or program action, and count the model calls. Then teach memory as something the program saves and puts back into the model's input.
