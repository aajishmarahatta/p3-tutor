# Agent architecture Resources

## Knowledge

- [Anthropic Engineering: Effective context engineering for AI agents](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  What goes into the context window, context rot, and keeping it lean. Use for: deciding what the assistant keeps in context.
- [Claude Platform Docs: Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Official docs for a client-side notes tool that the application runs. Use for: saving notes between sessions.
- [Anthropic: Managing context on the Claude Developer Platform](https://www.anthropic.com/news/context-management)
  Context editing (clearing stale results) together with the memory tool. Use for: long runs and token cost.
- [Anthropic: Contextual retrieval](https://anthropic.com/research/contextual-retrieval)
  Why chunks need added context, with measured retrieval results. Use for: searching long manuals.
