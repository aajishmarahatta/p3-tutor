# Agent architecture Resources

## Knowledge

- [Effective context engineering for AI agents (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, structured note-taking, just-in-time retrieval, sub-agents. Use for: what to keep in the window, memory design, and when to split work across agents.
- [Context windows (Claude docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window fills across turns and tool use, plus current limits and pricing notes. Use for: checking window sizes and long-prompt costs before choosing a model.
- [Building effective agents (Anthropic Engineering)](https://anthropic.com/engineering/building-effective-agents)
  The augmented LLM (retrieval, tools, memory), workflows versus agents, and "start simple". Use for: workflow-versus-agent decisions in later lessons.
