Context and memory: one page

WhereHoldsLasts
Context windowInstructions, tool definitions, conversation, tool resultsOne call; the program re-sends it every call
NotesShort per-student facts (training status, preferences)Between sessions; loaded back into context
Library (retrieval)Long manuals, split into chunksPermanent; only the top few chunks enter context

Rules

  • The model keeps nothing between calls; only text in the context exists for it.
  • Cost: the whole context is input tokens on every call.
  • More context can lower accuracy (context rot): aim for the smallest set of useful tokens.
  • Long loop: clear old tool results, compact, or use a sub-agent.
  • Memory tool: the model requests file operations; your code runs them and checks paths.
  • Retrieval: chunk, embed or index, search, put top chunks in context. Test the search separately.

Source: Anthropic, Effective context engineering for AI agents.
