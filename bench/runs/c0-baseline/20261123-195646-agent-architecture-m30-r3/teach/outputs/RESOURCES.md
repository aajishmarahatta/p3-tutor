# Agent architecture Resources

## Knowledge

- [Anthropic Engineering: Effective context engineering for AI agents](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on attention budget, context rot, compaction, note-taking, just-in-time retrieval and sub-agents. Use for: what to keep in context and how to manage it.
- [Claude docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official description of how the window fills each turn, context rot and prompt caching. Use for: what counts as input and cost.
- [Claude docs: Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Official client-side file memory: commands, storage mapping, path safety. Use for: wiring memory between sessions.
- [Searching for Best Practices in Retrieval-Augmented Generation](https://arxiv.org/pdf/2407.01219)
  Research study of chunking and retrieval choices. Use for: tuning manual search.
