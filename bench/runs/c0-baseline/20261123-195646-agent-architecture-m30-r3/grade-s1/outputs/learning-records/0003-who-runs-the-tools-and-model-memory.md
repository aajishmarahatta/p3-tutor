# Open misconceptions: the model runs the tools itself (M4) and remembers on its own (M3)

In quiz 0001, submission s1, Riley understood the loop, the need for a stopping condition and that the model picks tools from their descriptions. Riley also believed that the model itself runs the tools (M4), so a three-tool request counted as one model call, and that it remembers earlier sessions without help (M3).
Both beliefs matter for the makerspace assistant: M4 hides where cost comes from, and M3 hides the need to design memory.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6; correct on q1 and q3, and partial on q5, where the answer gave what happens but not why.

**Implications:** Before building on context and memory, revisit who does what in each step, counting the model calls. Check whether submission s2, taken four days later, still shows M4 and M3. Teach memory as something the program builds, not something the model has.
