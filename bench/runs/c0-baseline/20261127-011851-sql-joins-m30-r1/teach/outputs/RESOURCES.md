# SQL Joins Resources

## Knowledge

- [Debugging duplicated data in SQL query results (Metabase Learn)](https://www.metabase.com/learn/sql/debugging-sql/sql-logic-duplicated-data)
  Explains why one-to-many joins duplicate rows, how to detect it, and pre-aggregating in a CTE. Use for: duplicate rows after a join. Caveat: its code templates are sketches, and its join-type table should be double-checked against small examples.
- [Get rid of duplicates in a SQL JOIN (LearnSQL)](https://learnsql.com/blog/get-rid-of-duplicates-sql-join/)
  More examples of removing duplicates after joins. Use for: extra practice on DISTINCT versus pre-aggregation.

## Wisdom (Communities)

- r/SQL on Reddit (reddit.com/r/SQL)
  Large community. Use for: asking others to check a predicted row count on a small made-up table.
