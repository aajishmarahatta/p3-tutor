## Misconceptions (S6; tie each to where it first appeared)
1. The model remembers earlier chats itself (S1, S4). 2. A bigger window means no management is needed (S2, S3: context rot, cost). 3. Memory is the window (S4). 4. In retrieval the model searches by itself; the program runs the tool (S5). 5. Notes are saved automatically; the model must call the memory tool (S4).

## What each claim rests on
- S1 to S5 facts: primary, Anthropic Engineering, "Effective context engineering for AI agents" (context finite, context rot / attention budget, smallest high-signal set, compaction, tool-result clearing, structured note-taking, just-in-time retrieval and hybrid).

State once, as Anthropic's own internal evaluation, not a general guarantee. The memory tool being file-based and client-side comes from the sources given; confirm the wording against them.
