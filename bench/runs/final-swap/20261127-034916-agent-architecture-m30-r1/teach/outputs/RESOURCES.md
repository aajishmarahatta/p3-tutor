# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering, Sep 2025)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Defines the context window, context rot, compaction, structured note-taking and just-in-time retrieval. Use for: anything about what an agent keeps in context and how it remembers.
- [Article: "Managing context on the Claude Developer Platform" (Anthropic, Sep 2025)](https://claude.com/blog/context-management)
  Describes context editing (clearing stale tool results) and a file-based, client-side memory tool, with Anthropic's own evaluation figures (the baseline and measure are not defined). Use for: concrete mechanisms for clearing and persisting context, and cost effects.
